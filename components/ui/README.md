# shadcn/ui

Componentes oficiales de shadcn/ui obtenidos del repositorio https://github.com/shadcn-ui/ui, revisión `b0fcb58a6e7c4df1a88f7f6327b083592c2dfd9c`, directorio `apps/v4/registry/new-york-v4/ui`.

Se adaptó el import de `cn` a `@/lib/utils` y se tradujo el texto accesible de cierre del Sheet. Se conservó la licencia MIT en `LICENSE.md`. Los estilos de la página personalizan los componentes sin sustituir sus primitivas de Radix.

`components.json` permite continuar incorporando componentes con la CLI de shadcn cuando haya acceso al registro `ui.shadcn.com`.

Button y Accordion ahora exponen las versiones animadas de Animate UI. Su código, procedencia, adaptaciones y licencia están en `components/animate-ui`. Badge, Tabs y Sheet mantienen los componentes de shadcn/ui.
